# Security policy

Shipshape is a static, local-first web application. It has no accounts, backend, analytics, or database, and checklist progress stays in the visitor's browser.

If you find a vulnerability, do not include exploit details or private data in a public issue. Contact the maintainer through the email address listed on [Ahmed Shaban's GitHub profile](https://github.com/ahmedshaban022). Include the affected version, impact, and a minimal reproduction.

General bugs and accessibility issues should use the public issue templates.
