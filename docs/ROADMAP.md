# Shipshape roadmap

Shipshape stays intentionally small: it should help a frontend team run a useful pre-release accessibility pass without becoming an audit platform.

## Next

- Add optional links from each check to relevant WCAG techniques.
- Improve the copied report with project metadata and a review timestamp.
- Validate keyboard and screen-reader flows across current browsers.
- Add import and export for checklist progress without collecting user data.

## Later

- Offer focused checklist presets for forms, content pages, and web applications.
- Add a printable review summary.
- Explore community translations while preserving plain, practical language.

Ideas are welcome through the repository's feature-request template. Please keep proposals aligned with the local-first, no-account approach.
